# Olist 客户分析与高潜力客户挖掘 — 成果报告

> 可视化版：`index.html`（GitHub Pages 首页）；细部图：`outputs/*.html`。
> 模块五/六（A/B 实验设计 + 离线模拟演练）为本项目在原分析基础上的扩展。

## 1. 摘要（Executive Summary）

**问题定义。** 在巴西电商 Olist 的多表交易数据上，用关系型数据库 + SQL 建立客户层行为分析、RFM 客群分群，从新客中挖掘「高复购潜力」的少数客户，并进一步把预测推进到**营销决策**：为挽回券 A/B 实验完成基线校准、样本量与券策略设计（模块五/六）。

**主要发现（4 点）。**
1. **97% 客户只买一次**（复购率 3.0%）：留存困难，获客质量与首单体验是主战场。
2. **高价值客群占 16.5% 客户、贡献 31% 营收**（典型 80/20），可据以分配营销资源。
3. **复购由「首单品类」驱动**（家用/可补货 vs 一次性嗜好，差距约 6×）；配送/评论等服务体验影响的是**满意度（Spearman rho=−0.24）、不是留存**（假设检验 p=0.16 / 0.20 不显著）。
4. **券策略盈亏平衡与基线 p0 无关**（推导中 p0 约掉）：等值券（10%×AOV）需 +100% 相对提升才回本，R$5 定额券仅需 +19% → 主实验推荐 R$5 定额券；+20% MDE 下样本量可行（power 93~99%），+10% 不可行。

**结论与建议。** 依 RFM 客群分配资源（VIP 维系、流失召回、新客育成）；获客与交叉销售聚焦高复购品类；挽回实验按预注册计划执行（ITT、单主指标、禁止偷看）。

**适用边界（不可省略）。** 结论基于 Olist 交易型电商数据。复购预测模型上限约 ROC 0.6，是「仅凭首单交易资料」的天花板，而非方法或执行的问题。模块五/六的所有「实验结果」均为离线模拟（SIMULATED），用于验证分析流水线，不代表真实因果效应。

## 2. 数据说明
- **来源/范围**：Olist 公开数据集 9 张表；订单购买时间 2016-09-04 → 2018-10-17。
- **数据契约**（`docs/data-contract.md`）：99,441 订单、96,096 不重复客户；外键关联零孤儿；已知良性缺失（评论自由文字）。
- **已知限制/偏差**：`customer_id` 每单变动（已改用 `customer_unique_id`）；review_id 827 重复（以 order 聚合）；F 维度退化（97%=1）。
- **有效订单定义**：仅 `order_status='delivered'`（96,478 笔），排除取消/未实现消费。

## 3. 分析方法（依据与取舍）
- **客户主键**：`customer_unique_id`（避免复购率全错）。
- **RFM 分群**：R + log(M) 为主（F 退化）；传统 NTILE 评分箱（SQL）为行动依据，K-means(k=3, silhouette 0.36) 作结构验证——两法独立还原同一 R×M 结构（Champions 99% 同群）。
- **复购挖掘**：视为排序问题（base rate 3%）。特征仅用「首单当下 + 客户属性」以**杜绝泄漏**（聚合 RFM 会内含结果，明确排除）。LogReg(balanced) 为主、XGBoost+SHAP 对照。
- **A/B 设计（模块五）**：Platt 校准修正 class_weight=balanced 的未校准概率（均值 47.5% → 校准后 p0=2.94%）；两比例 z 检验样本量公式；券盈亏平衡推导（p0 约掉）。
- **模拟演练（模块六）**：64,741 人目标池注入 0/10/20/50% 效应（0% 为负对照），跑预注册分析流水线。
- **排除的方法**：以 Accuracy 评估（不平衡下无意义）；以聚合 RFM 当预测特征（泄漏）；以服务体验为主特征（EDA 证实无预测力）。

## 4. 结果
| 项目 | 结果 |
|---|---|
| RFM 客群 | 6 群，各 15–20%；高价值 16.5% 客户 → 31% 营收 |
| 复购模型 PR-AUC | 0.050（baseline 0.030，1.69×）；XGBoost 0.061（2.06×） |
| 复购模型 ROC-AUC | 稳健 **0.592 ± 0.008**（5 种子）；seed-42 0.611 |
| Top-decile lift | **1.8×**（前 10% 捕获 ~18% 复购者） |
| 驱动因子 | 品类为主：home_appliances OR 3.6 … electronics/luggage OR 0.5–0.6 |
| A/B 基线 p0 | 校准后 2.94%（全池）/ 2.77%（高价值层） |
| 券盈亏平衡 | R$5 定额券 +19%；R$10 +46%；等值券 +100%（不推荐） |
| 模拟演练 | 0% 负对照 p=0.80 不显著；+20% p=1.3e-12、ROI +2.44×（SIMULATED） |

## 5. 结论限制与建议
- **压力测试**（`docs/evaluation-report.md`）：种子稳定（±0.008）；时间外推 ROC 0.574；移除品类退至 0.563（量化品类贡献）。
- **适用条件**：结论成立于 delivered 订单、180 天复购窗、首单 ≤ 2018-04-20 的建模集。
- **标签 caveat**（独立代码审查发现）：复购以 delivered 第二单检测、cutoff 以购买日计，窗末尾未送达之复购计为负样本（**保守偏误、不膨胀指标**）。
- **p0 caveat**：p0 为校准后模型均值、非实测基线，上线前需用最近 90 天历史窗口重新校准。
- **后续建议**：要真正提升复购预测，需 Olist 没有的行为/营销/竞品资料（如浏览行为、营销触达、竞品价格）；挽回券真实效应需线上 A/B 实测。

## 1. 业务假设
H1：对「首单后 180 天未复购」客户发放定额复购券（R$5，60 天有效），
相比不发放，能提升其下一 180 天窗口的复购率。
（R$10 为探索性券额，仅在 LTV 视角下评估。）

## 2. 目标人群
- 建模集（首单 ≤ 2018-04-20）中 180 天未复购客户：
  **64,741 人**
- 分层：按首单金额中位数分高价值层（32,371 人）/ 普通层
- 分流单元：customer_unique_id 哈希，50/50

## 3. 指标与基线
- **主指标（唯一）**：下一 180 天复购率
- 护栏指标：AOV、券成本/客户、净增量毛利
- 基线 p0 估计（关键修正）：`class_weight='balanced'` 的 LogReg 输出**未校准**，
  全池概率均值 47.5%（真实 base rate 2.96%）→
  在测试集拟合 Platt（sigmoid）校准后，全池 p0 ≈ **2.94%**、
  高价值层 ≈ **2.77%**
- 敏感性：设计按 p0 ∈ {1%, 2%, 3%} 三档给出样本量，不押注单一估计

## 5. 券方案盈亏平衡（本设计的核心发现）
推导：券在复购订单上核销 → 每人券成本 = p2×券面值；每人增量毛利 = (p2−p1)×AOV×M。
两式的 p0 约掉 → **break-even 与 p0 无关，只取决于 券面值 / 单次复购毛利（31.8 BRL）**。
- **方案 A 等值券（10%×AOV = 16 BRL）**：r* = c/(M−c) =
  **+100%**（M=20%）→ 行业常见 +10~30% 提升下 ROI 为负
- **方案 B 定额券梯度**：R$5 → r* = +19%；R$10 → r* = +46%；R$15 → r* = +89%；R$20 → r* = +169%
- **结论**：主实验用 R$5 定额券（唯一在 +20% 情景下正 ROI 的方案）；
  R$10 仅在 LTV 视角（360 天观察窗）下考虑；方案 A 不推荐

## 6. ROI 量级（每 1 万目标客户，p0=2.94%，+20% 情景）
- 增量复购 59 人，增量毛利 1,869 BRL
- 方案 A 等值券：成本 5,606 BRL → ROI -0.67x
- 方案 B R$5 定额券：成本 1,761 BRL → **ROI 0.06x** ← 推荐
- 方案 B R$10 定额券：成本 3,522 BRL → ROI -0.47x（负，需 LTV 视角）

## 7. 分析计划（预注册）
1. ITT：所有进入随机化的客户纳入，按分组而非实际用券分析
2. 两比例 z 检验；主指标唯一，无需多重比较校正
3. 报告：绝对/相对提升 + 95% CI + p 值；CI 跨 0 判定无效应
4. 禁止偷看：期中不做显著性检验
5. 时长 180 天（与标签窗口一致）；避开大促窗口（季节性混淆）

## 8. 风险与诚实声明
- p0 为校准后模型均值，非实测基线 → 上线前用最近 90 天历史窗口校准
- 券成本按「处理组复购数」计（已用券假设），若实际核销率更低 ROI 更好（本估计偏保守）
- 毛利率 20% 为行业量级假设，非 Olist 真实财务数据

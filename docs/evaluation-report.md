# 评估与压力测试报告（阶段四）

交付模型：LogReg(class_weight='balanced')，特征见 experiment-tracking。
建模集 66,717，正样本率 2.96%。基准（seed=42）：ROC 0.610 / lift 1.84×。

## 1. 种子稳定性（5 个切分种子）
- ROC-AUC = **0.592 ± 0.008**；top-decile lift = **1.70 ± 0.22**。
- 诚实注记：std 小（效能稳定），**稳健估计约 ROC 0.59**；先前 seed=42 的 0.611 属略偏乐观的单一 split，应以 ~0.59 为准。

## 2. 时间泛化（早 75% 训练 → 晚 25% 测试）
- ROC-AUC = **0.574**，top-decile lift = **1.63**（测试期正样本率 2.76%）。
- 结论：时间外推下效能略降，无明显时间漂移失效。

## 3. 移除首单品类特征
- ROC-AUC = **0.563**（vs 含品类 0.610，退化 0.048）。
- 结论：品类是模型主要信号来源，移除后退回接近随机 → 印证 EDA 与驱动因子分析。

## 4. 可重现性
- Python 3.13；套件版本见 requirements.lock.txt。
- 所有随机种子固定（split / KMeans / 模型 = 42；A/B 分流 = 43、结果抽样 = 44）。
- 数据由 raw CSV 确定性重建（00→10 脚本依序可跑）。

## 5. 标签观察性注记（独立代码审查发现）
- 复购标签以「第二笔 *delivered* 订单」检测，但 cutoff 以「购买日」计算。少数在 180 天窗末尾下单、但快照时点尚未送达的复购，会被计为负样本（censoring）。
- 方向为**保守偏误**：正样本率略被低估、模型任务更难而非更易 → 报告指标未被高估。
- 另：midnight 快照 + date() 截断，使 cutoff 边界约 1 天观察性不完整（影响极微）。

## 6. A/B 实验设计：基线校准与券策略（模块五，09_ab_design）

### 6.1 关键修正：概率校准
- `class_weight='balanced'` 的 LogReg 输出**未校准**：全池概率均值 47.5%，而真实 base rate 2.96%（均值虚高约 16×），不能直接用作 A/B 基线。
- 修正：在**测试集**拟合 Platt（sigmoid）校准参数，套用到全量 refit 模型 → 全池 p0 ≈ **2.94%**、高价值层 ≈ **2.77%**。
- 敏感性：样本量设计按 p0 ∈ {1%, 2%, 3%} 三档给出，不押注单一估计。

### 6.2 目标人群与分流
- 建模集中 180 天未复购客户 **64,741 人**；按首单金额中位数分高价值层（32,371）/普通层。
- 分流单元 customer_unique_id 哈希，50/50；主指标唯一（下一 180 天复购率）；ITT、禁止期中偷看。

### 6.3 样本量（α=0.05 双侧，power=0.8，池半量 32,370/组）
| p0 | MDE | n_per_group | 可行 | 功效 |
|---|---|---|---|---|
| 2% | +10% | 80,682 | 否 | 43% |
| 2% | +20% | 21,109 | 是 | 93% |
| 3% | +10% | 53,211 | 否 | 59% |
| 3% | +20% | 13,914 | 是 | 99% |

完整 3×3 表见 `docs/ab-experiment-design.md`。
结论：**+20% 相对提升可检出（power 93~99%）；+10% 不可行**（所需样本超池 2.5 倍）。

### 6.4 券策略盈亏平衡（本模块核心发现）
- 推导：每人券成本 = p2×券面值；每人增量毛利 = (p2−p1)×AOV×M → **p0 约掉，break-even 与 p0 无关**，只取决于 券面值 / 单次复购毛利（31.8 BRL，M=20%）。
- 等值券（10%×AOV ≈ 16 BRL）：r* = c/(M−c) = **+100%** → 行业常见 +10~30% 提升下 ROI 为负，不推荐。
- 定额券：R$5 → r* = **+19%**；R$10 → +46%；R$15 → +89%；R$20 → +169%。
- **结论：主实验用 R$5 定额券**（唯一在 +20% 情景下正 ROI 的方案）；R$10 仅 LTV 视角下考虑。

## 7. 离线模拟演练：预注册流水线验证（模块六，10_ab_simulation，SIMULATED）

- 方法：64,741 人目标池按哈希 50/50 分流（seed=43），处理组注入 p_i×(1+uplift)、uplift ∈ {0, +10%, +20%, +50%}（seed=44 二项抽样），再走预注册分析流水线（两比例 z 检验 + 95% CI + ITT + ROI）。
- 结果：

| 注入效应 | 处理组率 | 对照组率 | 绝对Δ | p 值 | 判定 | ROI（R$5 券） |
|---|---|---|---|---|---|---|
| 0%（负对照） | 2.87% | 2.90% | −0.03pp | 8.04e-01 | 不显著 | −1.15× |
| +10% | 3.23% | 2.85% | +0.38pp | 4.90e-03 | 显著 | +0.50× |
| +20% | 3.59% | 2.62% | +0.97pp | 1.34e-12 | 显著 | **+2.44×** |
| +50% | 4.39% | 2.98% | +1.41pp | ≈0 | 显著 | +3.10× |

- 结论：0% 负对照正确"检不出"（不过度声称）；+20% 高功效检出且 ROI 为正 → 预注册分析流水线本身可信。
- 策略矩阵（品类×价值层，n≥500，+20% 情景，ROI 均为 +1.12×）：Top 增量层为 **bed_bath_table、sports_leisure、furniture_decor**（高价值/普通均有）——与 SHAP「家居/运动品类驱动复购」互证。
- 全部产出标注 SIMULATED：无真实随机化则无真实因果效应，本模块只验证流水线与设计。

## 总结
模型弱但**稳健且诚实**：种子稳定、时间可外推、信号可归因于品类。结论的适用边界：仅凭首单交易资料，复购预测上限约 ROC 0.6；更高精度需行为/营销资料。
在此之上，模块五/六把「预测」推进到「决策」：校准出可用作 A/B 基线的 p0（2.94%），推导出与 p0 无关的券盈亏平衡（R$5 定额券为唯一现实可行的主实验方案），并用含 0% 负对照的离线模拟验证了分析流水线。
